# Drop views/forwards — без просмотров и репостов в экспорте

Ветка: `drop-views-forwards-meta`

## Проблема

Каждый пост в common-файле заканчивался строкой метаданных Telegram:

```markdown
*👁 118 · 🔁 1*
```

Для архива текстов это лишний шум: цифры меняются со временем и не относятся к содержанию поста.

## Решение

Парсер больше не пишет `views` / `forwards`. Формат поста:

```markdown
### [2024-01-15 10:30 UTC](https://t.me/channel/123)

Текст поста…

---
```

## Изменённые файлы

| Файл | Что сделано |
|---|---|
| `parser.py` | Удалён блок `meta_parts` с `msg.views` / `msg.forwards` |
| `README.md` | Пример вывода без строки с 👁 / 🔁 |
| `docs/features/text-only-export.md` | Убраны устаревшие упоминания meta |

`update_liminalwriting.py` и `update_twonovelists.py` используют `fetch_and_export` — менять их не нужно.

## Миграция

Уже сохранённые common-файлы сами не очищаются. Перезапусти парсер / update-скрипт — новый экспорт будет без метаданных.

## Как проверить

В свежем `*_common.md` нет строк вида `*👁 …*` и `*🔁 …*`.
